# IsTheBarcodeBlank
An iOS app with a barcode/QR code scanner that gives you some facts about any barcode or QR code it can read.

# Why?

Why not?

## Really, why?

Apple provides native frameworks that have excellent document scanning capabilities, and it's fun to know what info a barcode contains.

## Contributing

Contributions are welcome! For LLM usage specifically, I like [the LLM policy used by the Rust language community](https://forge.rust-lang.org/policies/llm-usage.html).

## Localization

Translations are done with the help of machine translation using DuckDuckGo Translate and DeepL and my (non-native) knowledge of the supported languages, because my translation experience is limited to some university coursework. Corrections are welcome!
